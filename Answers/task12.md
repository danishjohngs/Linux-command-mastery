| command    	| Purpose                                                         	|
|------------	|-----------------------------------------------------------------	|
| pwd        	| Print Working Directory                                         	|
| ls -la     	| list the directory and shows the hidden directories and files.  	|
| cd         	| Change directory (helps to change one directory to another)     	|
| mkdir      	| create directory                                                	|
| touch      	| create empty file                                               	|
| cp         	| copy                                                            	|
| rm         	| remove/delete                                                   	|
| mv         	| move                                                            	|
| cat        	| display the contents of a file                                  	|
| less       	| used to view contents of a text file one screen at a time       	|
| nano       	| nano is text editor in linux                                    	|
| whoami     	| displays the current logged username                            	|
| id         	| displays the current user's details (uid,gid,groups,sub groups) 	|
| groups     	| shows the groups that the current user belong                   	|
| chmod      	| change permissions                                              	|
| sudo       	| gives temporary root access to a user for a command             	|
| ps aux     	| shows the snapshot of every running process on the system       	|
| top        	| shows the live details of every running process on the system   	|
| systemctl  	| it is a command line tool used to control services in linux     	|
| journalctl 	| used to view system & service logs                              	|
